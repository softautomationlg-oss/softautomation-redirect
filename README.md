# Redirect softautomation.it → www.softautomation.it

Pagina statica che porta chi digita `softautomation.it` (senza www) a `https://www.softautomation.it`.
Contiene solo questo: nessun contenuto del sito, nessuno script di terze parti, nessun cookie.
Il sito vero è nel repository privato del progetto. Vedi docs/DECISIONS.md (D-30) di quel repository.
